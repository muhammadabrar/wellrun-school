# Wellrun School — design system

Wellrun family (indigo `#4642ff`, ink `#16161d`, paper `#f7f7f8`, orange `#f26522`). Two personalities, one brand.

## Shared

- Fonts: Space Grotesk + Plus Jakarta Sans + Instrument Serif
- No emoji-as-icons (Lucide)
- Visible focus rings, 4.5:1 text contrast
- Respect `prefers-reduced-motion`
- English first; i18n keys ready for Urdu/RTL later

## Discover (Layer 1)

Booking + LinkedIn + Facebook for schools. Photo-first, trustworthy, thumb-friendly. Not a kids app. No claymorphism, no comic fonts.

- Mobile-first; desktop is usable only
- Large cover photos, sticky compare bar
- Cards over chrome

## Console (Layer 2)

Light, calm operations UI for school staff. High contrast, plain language, generous spacing. Delight is hidden (transitions.dev), not decorative chrome.

- Desktop-first (1440+)
- Sidebar + page title
- Number pop-in, skeleton reveal, spinner-to-check, sliding tabs, toasts
